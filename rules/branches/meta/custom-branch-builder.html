특정 도메인이나 복합 워크플로우 전용의 커스텀 HTML 분기 구조를 Harness² 방식으로 설계·검증합니다.

Model Tier: mid (중위 모델 권장) Effort: medium Skills: harness-propose-probe-compose

커스텀 분기 제작 4단계 (Harness² Propose–Probe–Compose)

  1. Propose: rules/branches/<domain>/<node>.html을 생성하고 <main class="rule-node" data-rule-id="..." data-parent="..." data-tier="..." data-effort="..." data-skills="..."> 속성을 채운다.
  2. Link: 부모 HTML의 <nav data-children>에 data-when 조건부 링크 1줄을 추가한다.
  3. Probe: python scripts/validate_harness.py와 python scripts/resolve_rule.py --task "..."로 토큰 절감률 및 라우팅 정확도를 검증한다.
  4. Compose: AI 블록(<!-- AI-RULE-START --> 내부)을 1,500B 권장(상한 2,800B) 이내로 다듬고, 외부 CSS/JS만으로 인간 UI를 유지한다.
