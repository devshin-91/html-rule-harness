최상위 모델 · 탁월한 크래프트 (Frontier Craft)

최상위 추론·멀티모달 모델의 과잉 프롬프팅(Over-prompting)을 피하고 Anti-Slop·2-Pass 미학·시각 피드백 루프로 압도적 결과물을 도출합니다.

실행 규칙 (Frontier Discipline)

  • 과잉 지시·낭비 문구 금지: 최상위 추론 모델에 "단계별 생각", "여러 대안 탐색(2.4~7.4배 낭비)", "최대 확신 검증(18배 낭비)" 같은 문구(arXiv:2608.01347)를 넣지 말고 목표·성공 기준·금지 제약만 주며, 깊이는 네이티브 파라미터(reasoning_effort/thinkingLevel)로 제어한다.
  • 2-Pass Anti-Slop & 과잉 숙고 차단: 구현 전 색 토큰·폰트 페어링·비대칭 레이아웃·Design Dials·핵심 시그니처 1개를 먼저 선언하고 AI 상투어를 금지하되, 지각·미학 과제에서 장황한 CoT로 전체 일관성을 해치지 않는다(arXiv:2410.21333).
  • 패턴 완성 편향 교정 루프: 프론티어 모델도 UI 반복 패턴 편향(최대 80.22%)으로 시각 이상을 무시하고 관성 코드를 내므로, 텍스트 Slop Inventory → 유지 항목 → 최소 수정안 작성 후 브라우저 스크린샷·리뷰 모델로 교차 검증한다.
